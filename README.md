## 1. 一句话

**市面记账 App 是「一本账，按日期翻页」；这个 App 是「若干分类钱包，每个钱包自己记一本账」。**

打开 App 第一眼不是流水，而是你亲手建的格子：🍜 饮食 · 🛒 生活 · 💼 兼职。
点进去才是这一类的账：顶部是收入/支出/结余，下面是按时间倒序的每一笔。

时间维度没有消失，只是**从主导退到了类内排序**。

## 2. 和主流记账 App 的差异

| 维度 | 主流（随手记 / 鲨鱼记账 / MoneyWiz） | 分类账 |
|---|---|---|
| 首页 | 全部流水混排 / 月度报表 | **自定义分类卡片网格** |
| 分类的角色 | 记账时填的标签，藏在二级 | **一级容器**，就是导航本身 |
| 记账路径 | 首页 → ＋ → 选类型 → 填 → 选分类 → 存 | 首页 → 点分类 → 填金额 → 存 |
| 时间 | 主导维度（日历/月视图） | 类内排序与分组 |
| "这个月吃饭花了多少" | 进报表筛选 | 卡片上直接写着 |
| 心理模型 | 一个总账本 | 若干分类钱包 |

**代价与对策**（原设计的取舍都保留了）：

- 全局视角弱 → 首页顶部常驻一行「本月支出 / 收入 / 结余」，可点折叠
- 分类多了首页会长 → 长按进整理模式调顺序；不用的归档隐藏
- 跨类查询不便 → v1 未做全局搜索，靠分类页「全部」+ 月份翻页顶住

参考系：英文世界的**信封预算法（Envelope Budgeting / YNAB）**是同一思路，但中文记账 App 基本没把它做成一级导航。

## 4. 交互规则（实现细节）

| 项目 | 规则 |
|---|---|
| 金额存储 | **整数分**（¥45.50 → 4500），避免浮点误差 |
| 金额输入 | 最多 2 位小数；整数部分 ≤ 7 位；0 元禁用保存 |
| 默认方向 | 分类的 `defaultDir`；同一分类**记住上次方向**（`settings.lastDir`） |
| 时间 | 默认当前时刻；可改任意时间；未来时间允许 |
| 排序 | `at` 倒序，同一时刻按 `createdAt` 倒序 |
| 编辑 | 金额/方向/时间/备注/分类全可改；改分类 = 把这笔移走 |
| 删除 | 软删除 + 5 秒撤销条 |
| 分类删除 | 无账目→直接确认；有账目→「归档 / 迁移 / 连账删除」三选一 |
| 归档 | 首页隐藏，账目与统计保留，可取消 |
| 排序调整 | 长按卡片进整理模式，`↑ ↓` 交换；sort 值冲突时整体重排 |
| 时间范围 | 本月 / 全部；本月模式可 `‹ ›` 翻月份 |
| 空状态 | 首页无分类 → 引导建第一个；分类内无账目 → 提示记第一笔 |
| 返回键 | 先关弹层 → 再退页面 → 首页才退出 App（`window.__back`） |
| 金额显示 | 千分位 + 两位小数；收入 `+`、支出 `−`，同时用颜色和符号表达 |

## 5. 数据模型

```jsonc
{
  "version": 1,
  "categories": [{
    "id": "c_xxx", "name": "饮食", "emoji": "🍜", "color": "#F97316",
    "defaultDir": "out",          // out 支出 | in 收入
    "sort": 10,
    "budgetMonth": 200000,        // 分；null 表示不设预算
    "archived": false,
    "createdAt": "2026-11-26T20:00:00+08:00"
  }],
  "entries": [{
    "id": "e_xxx", "catId": "c_xxx",
    "amount": 4500,               // 分
    "dir": "out",
    "at": "2026-11-26T12:30:00+08:00",
    "note": "午饭 牛肉面",
    "createdAt": "...", "updatedAt": "...",
    "deletedAt": null             // 软删除标记
  }],
  "settings": {
    "theme": "auto",              // auto | light | dark
    "compactList": false,         // 不按天分组
    "showColors": true,           // 收支颜色
    "homeCollapsed": false,       // 首页汇总折叠
    "lastDir": {}                 // 每个分类上次用的方向
  }
}
```

时间统一存带时区的 ISO 8601 字符串；分组时按本地时区切天。

## 6. 存储与备份

**APK 里不走 WebView 的 localStorage**，这是刻意的：

`file://` 页面下的 localStorage 在部分 WebView 版本行为不稳定（可能写不进或清缓存就丢）。所以壳子里实现了一套原生文件存储，通过 `AppBridge` 暴露给页面：

1. 写入 → 先写 `*.tmp` → `fsync` → 删除旧文件 → 重命名（**原子替换**，断电也不会写坏）
2. 位置 → 应用私有目录，随 App 卸载一起删除
3. 浏览器里（预览用）自动退回 localStorage，同一份代码两种存储

**备份**：设置 → 导出备份 → 复制 JSON 文本（走系统剪贴板桥）；导入粘贴即可覆盖。
之所以不用"导出成文件"，是因为 WebView 的文件下载在不同 ROM 上权限/路径差异太大，剪贴板反而最可靠。

## 8. 技术实现

### 8.1 前端（`www/`）

- 纯 HTML + CSS + 原生 JS，**零依赖、零构建**
- 单页应用，自己维护视图栈（`stack`）+ 弹层栈（`sheets`），不用路由库
- 全量重渲染（每屏 DOM 极小），只有记账弹层做局部更新以保住输入焦点
- 体积：`index.html` 614B + `app.js` 46.3KB + `style.css` 18.4KB

### 8.2 Android 壳（`android/`）

- 单个 `MainActivity`（约 330 行），纯 framework API，**不引入 AndroidX**
- `WebView` 加载 `file:///android_asset/index.html`，全部资源内置
- `assets` 摊平在根目录（原因见 9.3 的坑）
- 返回键拦截 → 调页面 `window.__back()` → 返回 `false` 才 `finish()`
- `configChanges` 接管 `uiMode`，切换深浅色不重建 Activity
- 无 `INTERNET` 权限，`usesCleartextTraffic=false`，`shouldOverrideUrlLoading` 一律拦掉
- 规格：`com.catledger.app` · minSdk 24 · targetSdk 34 · 62,433 字节

### 8.3 桥接口契约（`window.AppBridge`）

| 方法 | 方向 | 说明 |
|---|---|---|
| `storageGet(key) → String\|null` | JS→原生 | 读私有目录文件；无文件返回 null |
| `storageSet(key, value) → boolean` | JS→原生 | 原子写入 |
| `systemDark() → "1"\|"0"` | JS→原生 | 系统是否深色 |
| `setStatusBarColor(dark: boolean)` | JS→原生 | 同步状态栏/导航栏配色与图标明暗 |
| `copyText(text)` | JS→原生 | 剪贴板 + Toast |
| `toast(msg)` | JS→原生 | 原生 Toast（备用） |

前端全部用 `try/catch` 包住调用，桥不存在时自动降级到浏览器行为 —— 所以同一份代码既能装进 APK，也能用浏览器打开调试。

## 9. 构建（不用 Gradle，也不装 Android Studio）

### 9.1 一次性准备

```powershell
node scripts/fetch-chunks.mjs          # 从腾讯云镜像并行下载（约 115MB，1~2 分钟）
# 解压到 .sdk\（见 scripts\ 里的说明或直接 Expand-Archive）
python scripts/make-icons.py           # 生成 5 个密度的图标
```

### 9.2 出包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build-apk.ps1
# 产物: apk\catledger-1.0.0.apk
```

流程：`aapt2 compile` → `aapt2 link` → `javac --release 8` → `d8` → 塞 `classes.dex` → `zipalign` → `apksigner`。
全程约 5 秒，无需联网。

### 9.3 构建时踩到的三个坑（已固化进脚本）

1. **aapt2 只认相对路径。** 本机沙箱下用绝对路径会报 `failed to open directory`，所以脚本 `Push-Location build\` 之后全部用相对路径。
2. **aapt2 会把 assets 子目录写成反斜杠。** 生成 `assets/www\app.js` 这种条目，WebView 按 `/` 找文件直接 404（装上就是白屏）。解决：前端资源摊平到 `assets/` 根目录，并在打包后断言"包内不能有反斜杠路径"。
3. **`-I android.jar` 传中文绝对路径会静默失效。** aapt2 只打一行 warning，然后把 `windowLightStatusBar` 等属性**悄悄丢掉**（主题只剩 3 个属性）。解决：把 `android.jar` 拷进构建目录，`-I android.jar`。修复后 8 个属性全部解析。

## 11. 与原设计稿的差异

| 原计划 | 实际 | 原因 |
|---|---|---|
| 左滑删除 | 改为编辑弹层内删除 + 5 秒撤销 | 触控误滑更多，面板删除更稳且可撤销 |
| 独立"总览"页 | 未做，用首页顶部汇总行 | 原设计里的推荐方案，一屏解决 |
| PWA + APK 双形态 | 只做 APK | 你决定不再考虑 iOS |
| 预算列为 v1.1 | v1 就做了（分类月度预算 + 进度条） | 实现成本低，且分类即预算单元很自然 |
| 导出为文件 | 改为复制 JSON 文本 | WebView 下载路径在不同 ROM 上不可靠 |

## 12. 已知限制

1. **未上真机验证**（见上）。
2. 自签名证书有效期 10,000 天，但**证书文件丢了就只能卸载重装**（会丢数据）。
3. 卸载 App 会删除全部数据 —— 卸载前先导出。
4. 国产 ROM 可能对"未知来源安装"有额外拦截，需要手动放行。
5. 无图表、无搜索、无云同步、无多币种（见第 13 节）。
